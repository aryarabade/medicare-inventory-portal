# Medicare Inventory Portal

A Medical Inventory Management System developed using Node.js, Express.js, SQL Server, HTML, CSS, JavaScript and Bootstrap.

## Features

- Admin Login
- Add Medicines
- View Medicine Stock
- Dispense Medicines
- Low Stock Alerts
- Expiry Alerts
- Search Medicines
- Dispense History Tracking

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
- Microsoft SQL Server

## Project Structure

```text
frontend/
backend/
database/
```

## Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Configure SQL Server

Run:

```sql
schema.sql
```

inside SQL Server Management Studio.

### Start Backend

```bash
npm start
```

Server runs on:

```text
http://localhost:5000
```
